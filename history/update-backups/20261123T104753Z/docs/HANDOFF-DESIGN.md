# Portable context handoff design — flat ZIP root v2

The large runtime library is authoritative for Blender assets, source CSV, SQLite and revision outputs. The portable handoff ZIP is a current-state **snapshot** for new sessions; it is deliberately not a runnable library. It includes the 276 V00 full source rows, all 3,036 pose index/hash records, dependency hashes, tracking snapshot, documentation, scripts and rig map. Excludes `.blend`, rendered images, database, historical pilots and full original CSV. Run `scripts/package-library-for-remote.py` from the full library; it produces `spose-remote-handoff-{UTC}.zip` **without a `remote/` wrapper**. New sessions extract the contents directly and run `python scripts/check_handoff.py`. Drafts from that handoff are still pinned to the full library's pair/source hashes; receiving full library validates again before Blender. Stale handoffs must be regenerated after catalog, pair or progress changes. Do not infer new accepted poses from a static old handoff.
