# Cold-start handoff contract

`python scripts/package-library-for-remote.py` creates a **flat-root compact context ZIP** (not a runnable library). It retains current ROADMAP, progress snapshots, V00 catalog rows, all source IDs and SHA-256 dependencies, rig mappings, operating docs and lightweight metadata, excluding large `.blend` assets and renders. Upload a combined batch feedback ZIP separately when discussing visual problems.

The assistant should not insist on clean geometry or accepted status before continuing. A future session can schedule the next five as soon as the user asks, while preserving the problem list and prior version references. All source/geometry gate labels are reference metadata.
